# Internationalization (i18n) Documentation

This project uses [next-intl](https://next-intl-docs.vercel.app/) for internationalization support.

## Current Languages

- **English (en)** - Default language
- **German (de)** - Fully translated

## How It Works

1. **Automatic Detection**: The middleware automatically detects the user's browser language and redirects to the appropriate locale
2. **Manual Switching**: Users can switch languages using the language picker in the header
3. **URL Structure**: URLs are prefixed with the locale code (e.g., `/en`, `/de`)

## Adding a New Language

To add support for a new language (e.g., French), follow these steps:

### 1. Create Translation File

Create a new JSON file in the `messages/` directory:

```bash
messages/fr.json
```

Copy the structure from `messages/en.json` and translate all the values:

```json
{
  "header": {
    "menu": {
      "home": "Accueil",
      "impressions": "Impressions",
      ...
    }
  },
  ...
}
```

### 2. Add Locale to Routing Configuration

Update `src/i18n/routing.ts`:

```typescript
export const routing = defineRouting({
  // Add your new locale here
  locales: ['en', 'de', 'fr'],  // Added 'fr'
  defaultLocale: 'en',
  localeDetection: true,
});
```

### 3. Add Language to Language Switcher

Update `src/components/Header/LanguageSwitcher.tsx`:

```typescript
const languages = [
  { code: "en", label: "English", flag: "🇬🇧" },
  { code: "de", label: "Deutsch", flag: "🇩🇪" },
  { code: "fr", label: "Français", flag: "🇫🇷" },  // Add your new language
];
```

### 4. Test Your Changes

1. Start the development server:
   ```bash
   npm run dev
   ```

2. Visit your new locale URL:
   ```
   http://localhost:3000/fr
   ```

3. Test the language switcher in the header

## Translation Keys Structure

The translation files are organized hierarchically:

```
header/           - Navigation menu items
hero/             - Main hero section
features/         - Feature cards
testimonials/     - User testimonials
footer/           - Footer content
breadcrumb/       - Breadcrumb navigation
pages/            - Page-specific content
  installation/   - Installation page
  impressions/    - Impressions page
installation/     - Installation section content
impressions/      - Impressions section content
```

## SEO Considerations

The `src/app/sitemap.ts` automatically includes all configured locales. No changes needed when adding new languages.

## Best Practices

1. **Keep Keys Consistent**: Use the same key structure across all language files
2. **Test Thoroughly**: Always test your translations in context
3. **Maintain Accuracy**: Ensure translations are culturally appropriate and accurate
4. **Handle Missing Keys**: next-intl will fall back to the default locale if a key is missing

## Troubleshooting

### Translations Not Showing

1. Verify the locale code is added to `routing.ts`
2. Check that your JSON file is valid (no syntax errors)
3. Ensure the translation keys match exactly (case-sensitive)
4. Clear the `.next` cache and restart the dev server

### Language Switcher Not Working

1. Verify the locale code matches in all three places:
   - Translation file name (`messages/[locale].json`)
   - Routing configuration (`src/i18n/routing.ts`)
   - Language switcher (`src/components/Header/LanguageSwitcher.tsx`)
